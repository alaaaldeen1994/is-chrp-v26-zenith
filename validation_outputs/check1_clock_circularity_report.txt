NOTE: The 'synchrony' variable in neuros_substrate_service.py is implemented as
  σ(population_spikes) / μ(population_spikes)  [coefficient of variation]
This is a DISPERSION measure, NOT synchrony. High CV = irregular firing,
which in cardiac context maps to arrhythmia risk — the gate is directionally
correct but the variable name inverts the cardiac intuition. Should be renamed
'spike_cv' or 'pop_dispersion' to avoid confusion with electrophysiologists.
