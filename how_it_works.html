An exhaustive item-by-item guide to every control in the Zenith v27.0 GOLD sidebars.

A-Z LEFT SIDEBAR
(Protocol Design)

Control Group 01 Reprogramming Factors (Dropdown)

Select from canonical (OSKM, Lin28) or synthetic cocktails (DRP-Alpha-12). This initializes the target transcription factor (TF) weights for the population.

Primary Action Transfect Population (Button)

Executing this command immediately applies the selected factor weights to the live cell cohort. Triggers the transfect_population() backend function.

Outcome: Instant latent state shift
Specialized Mode H1FOO-DD (Checkbox)

Enables a specialized 2024 oocyte-derived factor boost that enhances epigenetic fluidity for high-risk HMVEC rejuvenation trials.

Safety Control MPTR (Nilus Lab Rejuvenation)

Limits the reprogramming to the Methylation Pattern Transition (MPTR). Prevents pluripotency induction, ensuring 100% identity stability.

Control Group 02 Perturbations (Induce Tumor / SMA)

Manually trigger pathological states. Use this to stress-test your rejuvenation cocktail's resilience against oncogenic (Induce Tumor) or atrophic (Induce SMA) drift.

Control Group 03 Genomic Knockout (Dropdown)

Simulate the deletion of specific genes (e.g., TP53, PTEN). This is critical for verifying the safety of non-oncogenic protocols.

Stress Module Apply Knockout & Stress Test

Executes the knockout. The "Stress Test" badge activates a high-frequency SDE simulation to check for population fragmentation.

Outcome: Safety Delta Verification
Data Ingestion Upload Research Data (Button)

Ingests external PDF/CSV research manifests. The AI reorganizes the console based on the specific genomic findings of your uploaded data.

A-Z RIGHT SIDEBAR
(AI Discovery Engine)

NLP Input Semantic Target (Textarea)

The primary interface for clinical intent. Write your biological goals here (e.g., "10-year age reversal of HMVECs"). Triggers parse_intent().

Binary Logic Reprogramming Mode (Full / Partial)

Toggle between total state reset (Full) and identity-preserved rejuvenation (Partial). This changes the Neural SDE update rule from stochastic drift to convergent rejuvenation.

Data Bridge Gene Lookup (Fetch Button)

Type a gene (e.g., KLF2) to fetch live sequence data from UniProt Swiss-Prot. This sequence is used for your AlphaFold 3 structural validation.

Structural Bridge AF3 Results (pLDDT / ipTM)

Manual input fields for structural docking scores. These must be populated after running external AF3 jobs to lock the protocol's physical validity.

Pharmacology Bridge Expert Pharmacology Console

Inject synergistic small molecules (e.g., Vitamin C, GSK-J4) into the simulation. Use the "Add" button to layer chemical interventions over genetic ones.

MASTER EXECUTION Initiate Hybrid Discovery

The final CTA. This unifies all left and right sidebar configurations into a single, institutional-grade protocol manifest.

Outcome: Unified GOLD Protocol Manifest
