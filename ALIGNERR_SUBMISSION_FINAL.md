### 2. Project Description (The "Final Deliverable")
- **Project Name**: Zenith Ultra-V4: Generative High-Definition Foundation Model
- **Summary**: A high-fidelity biological foundation engine designed to simulate and optimize cellular state transitions (reprogramming). ### 3. The "Behind-the-Scenes" (The Data Alignerr Wants)

#### A. The Initial Request / Problem
- **Prompt**: "Build a 'Bio-iOS'—a platform that moves cellular rejuvenation from stochastic wet-lab trial-and-error to in-silico precision engineering. The system must prevent oncogenic risk and ensure epigenetic stability."

#### B. The Referenced Data
- **Real-World Training Data**: 150,000 observations from the **Human Cell Atlas (HCA)** (specifically cardiac and stem cell entries).
- **Genetic Manifolds**: 5,000 gene HD transcriptomic data used for Epigenetic Stability (ESI) benchmarking.

#### C. The "Drafts" and Iterations (The Process)
- **Evolution**: The project evolved through 7 major phases of algorithmic refinement (documented as `careful_phase2.py` through `careful_phase7.py`).
- **Audit Process**: Every claim in the documentation was verified against the codebase. For example, auditing the 3.06 billion parameter count by calculating the Residual FFN Trunk layers in the `bridge_server.py` implementation.

#### D. Tool Usage & Tech Stack
- **AI/ML**: PyTorch (Neural SDEs, Transformer Core), scvi-tools (HCA embedding).
- **Backend**: FastAPI (Python), Docker, Railway.
- **Frontend/Viz**: Three.js (3D manifold projection), Canvas-based GPU rendering.
- **AI Assistance**: Integrated OpenAI API for autonomous protocol discovery.
