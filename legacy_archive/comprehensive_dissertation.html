03. Mathematical Derivations: SDEs & Hill Dynamics

The mathematical heart of IS-CHRP is the simulation of **Stochastic Gene Regulatory Networks**. Unlike simple linear models, biological systems are intensely non-linear and cooperative.

3.1 Cooperative Binding Switch (Hill Equations)

The probability of a gene being "On" is not a straight line. It is a Sigmoid curve. We use the **Coupled Hill Equation** to model how Gene A regulates Gene B:

\[ R(A) = \frac{A^n}{K^n + A^n} \]

Where \(n\) is the cooperativity (Hill Coefficient) and \(K\) is the threshold. In our simulation, \(n\) values range from 1 to 4, allowing us to model soft regulators and sharp, "all-or-nothing" switches.

3.2 Langevin Dynamics: Dealing with Noise

Real cells are noisy. To model this, we use **Langevin Dynamics**, which adds a "Random Walk" component to the gene's movement. The update rule for a gene \(g\) at time \(t\) is derived as:

\[ g_{t+\Delta t} = g_t + \underbrace{\left( \sum \text{Inputs} - \text{Degradation} \right) \Delta t}_{\text{Deterministic}} + \underbrace{\sigma \sqrt{\Delta t} \cdot \xi}_{\text{Stochastic}} \]

Where \(\xi\) is a random number from a normal distribution. This is solved using the **Euler-Maruyama Numerical Method**, ensuring that even on a web browser, the math remains industrially accurate.

04. Physics & Computational Optimization

To simulate 2,000+ agents without lagging, the program must solve the **N-Body Collision Problem**. This is a classic computational bottleneck.

4.1 Spatial Partitioning (Spatial Hashing)

A "Brute Force" approach checks every cell against every other cell, which is \(O(N^2)\). For 2,000 cells, that is 4,000,000 checks. IS-CHRP uses a **Spatial Hash Grid** to reduce this to \(O(N)\). The world is divided into a grid, and each cell only "checks" the 8 adjacent boxes. This drops the workload to only ~18,000 checks—a **200x speed increase**.

// Optimization Implementation: Spatial Hashing
const cellSize = 50; 
const grid = new Map();

function buildSpatialGrid(agents) {
    grid.clear();
    for (let agent of agents) {
        let gx = Math.floor(agent.x / cellSize);
        let gy = Math.floor(agent.y / cellSize);
        let key = `${gx},${gy}`;
        if (!grid.has(key)) grid.set(key, []);
        grid.get(key).push(agent);
    }
}

4. The server "decodes" the latent coordinate back into the full **20,000 gene list**.

5. The results (e.g., GAPDH, MYH7, MAP2) are sent back to the browser UI.
