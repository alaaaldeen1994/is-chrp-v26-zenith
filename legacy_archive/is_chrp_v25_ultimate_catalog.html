03. Mathematical Framework: SDEs & Stochastic Logic

The IS-CHRP engine does not use simple "If/Then" logic. It uses **Stochastic Differential Equations (SDEs)** to ensure that every cell is a unique, semi-random living entity.

The Langevin Equation for Gene Dynamics

Each of the 12 genes \(x_i\) evolves over time following a Langevin-style rule. This rule combines the deterministic behavior of the biology with the random "noise" of life:

\[ d x_i = \left( \underbrace{ \sum_{j=1}^{12} \frac{a_{ij} x_j^n}{K_{ij}^n + x_j^n} }_{\text{Coupled Hill Logic}} - \underbrace{ \gamma_i x_i }_{\text{Degradation}} \right) dt + \underbrace{ \sigma_i \sqrt{dt} \cdot \eta(t) }_{\text{White Noise}} \]

Where:

  • \(a_{ij}\): The strength of interaction between gene \(j\) and gene \(i\).
  • \(n\): The Hill Coefficient (the "sharness" of the switch).
  • \(K\): The dissociation constant (the threshold of activation).
  • \(\eta(t)\): A random variable sampled from a normal distribution \(N(0,1)\).

04. Physics & Computational Scaling: Spatial Hashing

Simulating 2,000 agents in a web browser is a massive performance challenge. If every cell has to check every other cell for collisions, it results in an \(O(N^2)\) bottleneck which would crash the user's computer.

O(N) Optimization vs. Brute Force

IS-CHRP v25 solves this using a **Spatial Partitioning Grid (Spatial Hashing)**. Instead of checking 4,000,000 combinations, the world is carved into a grid. Each cell only checks its immediate neighbors.

    constructor(size) { this.cellSize = size; this.grid = new Map(); }
    
    // Hash function: Converts (x,y) to a unique string key

        return `${Math.floor(x / this.cellSize)},${Math.floor(y / this.cellSize)}`;
    }

    // Insert Agent into the grid
    insert(agent) {

        if (!this.grid.has(key)) this.grid.set(key, []);
        this.grid.get(key).push(agent);

05. Deep AI: The scVI Latent Space Bridge

The most sophisticated part of IS-CHRP v25 is the **Multi-Generative Bridge**. While our simulation only tracks 12 core genes, a real human cell has 20,000 genes. How do we fill that gap?

Figure 5.1: The Variational Autoencoder (VAE) Bridge architecture. Mapping the 12D Synthetic State to the 20,000D Human Transcriptome.

Latent Space Expansion (VAE-scVI)

We utilize a **Variational Autoencoder (VAE)** architecture. The logic follows a 4-step process:

  1. Observation: The simulation captures a 12-dimensional snapshot of a specific cell.
  2. Encoding: This 12D vector is sent to the Python Bridge Server, which maps it to a **Latent Represention (z)**.
  3. Projection: The latent space is a 10-dimensional manifold representing real human scRNA-seq data (from thousands of real patients).
  4. Decoding: The server "decodes" the latent point back into a high-resolution list of **20,000 genes**.

This allows the "High-Res Transcriptome" panel to show real biological markers like **GAPDH**, **MYH7**, and **TUBB3**. These genes are not coded into the simulation; they are *predicted* by the AI based on the "Deep Logic" it learned from real human cells. This is the **Synthetic-to-Real Bridge**.
